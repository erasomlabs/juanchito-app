# AGENTS.md — Juanchito Console (App Android)

## 1. Identidad y Esencia
- **Producto:** Juanchito Console — Mini consola retro de juegos
- **Esencia:** Herencia lúdica de Juanchito Recreaciones, pero producto autónomo
- **Slogan:** Juegos retro para todos

## 2. Técnico
- **Plataforma:** Android (Gradle 8.4)
- **Lenguaje:** Kotlin/Java
- **Arquitectura:** Código modular, pruebas locales de compilación
- **12 minijuegos retro:** Píxel World / PlayZone (HTML5, CSS3, JavaScript puro)

## 3. Identidad Visual
- **Paleta:** Herencia de Juanchito (#FFD93D, #6EC1E4, #FA7268) adaptada a UI de app
- **Estilo:** Retro, lúdico, colorido

## 4. Audiencia
- Niños y familias
- Usuarios que buscan entretenimiento casual retro

## 5. Autonomía y Supervisión
- Libertad técnica en desarrollo y optimización
- Punto de control: compilación local exitosa antes de push

## 6. Skills
- No aplica senior-frontend (app nativa Android, no sitio web)
